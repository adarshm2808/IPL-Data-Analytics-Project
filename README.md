IPL Data Analytics Project
Overview

This project analyzes multi-season Indian Premier League (IPL) match and ball-by-ball data to uncover insights related to team performance, player performance, opponent matchups, bowling, batting, and venue characteristics. The project follows an end-to-end analytics workflow using Python, SQL, Excel, and Power BI.

Tech Stack
Python (Pandas, NumPy)
PostgreSQL / SQL
Power BI
Excel
CSV / JSON Dataset
Project Workflow

1. Data Extraction & Preparation (Python)
Processed multi-season IPL JSON match data.
Extracted match, player, innings, delivery, and wicket-level information.
Cleaned and transformed raw data into structured CSV datasets.
Created analytical datasets for player, team, opponent, and venue analysis.

2. SQL Analysis
Performed analytical queries to answer questions such as:
Top run scorers and wicket takers
Team-wise wins, losses, and points
Team vs opponent performance
Player vs opponent performance
Season-wise player performance
Venue-wise match statistics
Batting and bowling performance

4. Dashboard Visualization (Power BI)
Created an interactive dashboard featuring:
Team Performance Analysis
Batter Performance Analysis
Bowler Performance Analysis
Venue Analysis
Season and team filters
KPI cards and performance trends
Head-to-head analysis
Compared team performance across multiple IPL seasons and opponents.
Identified top-performing batters and bowlers based on runs and credited wickets.
Analyzed batting and bowling performance across Powerplay, Middle, and Death overs.
Evaluated venue trends using scoring patterns, wickets, and chasing vs batting-first performance.
Developed player-level analysis to compare performance across seasons and against specific opponents.
Objective

The objective of this project was to transform raw IPL match data into meaningful player, team, opponent, and venue insights through a complete data analytics pipeline.
